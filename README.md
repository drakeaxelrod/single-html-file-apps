# 🧩 Single File Web Apps

A collection of self-contained, zero-dependency web applications built as single `.html` files. These apps run entirely in the browser — no build tools, no servers, no nonsense.

## 📦 What's Inside

Each file in this repository is a standalone web app. Just download and open in your browser. Or use them directly from GitHub.

### Features

- 🧱 Single File
- 🚫 No external dependencies
- 🗂 Easy to clone, fork, or embed
- ⚡ Instant load, even offline
- 🛠️ Great for demos, tools, and quick prototypes

## 🗃 Apps

| App Name      | Description                             |
| ------------- | --------------------------------------- |
| `pong.html`   | A simple Pong game built with Phaser 3. |
| `slots.html`  | A classic slot machine game.            |
| `snake.html`  | A retro Snake game.                     |
| `wishly.html` | A minimalist wish list app.             |
| `pong.py`     | A Python version of the Pong game.      |

> 💡 Tip: Use your browser’s `Save As` feature to download any app locally.

## 📁 Usage

1. Clone or download this repo:
   ```bash
   git clone https://github.com/drakeaxelrod/single-html-file-apps.git
   ```
2. Open any `.html` file in your browser.
3. Enjoy the app!
